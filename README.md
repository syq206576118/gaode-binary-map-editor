# 高德地图二值化编辑器

把配色与示例相近的高德小区地图截图转换为白底黑线地图，并在本地网页中继续编辑。

> 当前第一版只保证在 macOS 上可用。地图图片和标注全部在本机处理，不会上传到网络。

## 第一版能力

- 自动识别绿色区域，去除文字、图标和原图颜色干扰。
- 自动保留道路边界和楼栋四周轮廓，生成白底黑线初始地图。
- 用矩形画可行区（白色）和规则障碍区（黑色）。
- 点击封闭白区可预览并填充不规则障碍区；检测到 1–8 px 的疑似边界缺口时，会用橙色圆圈和十字标出修补位置。
- 用两点画障碍线，可设置像素线宽、移动端点或删除；默认吸附为水平/垂直，也可关闭后画任意角度。
- 框选已有楼栋作为模板，按矩形框范围原样复制当时的二值内容，包括楼内修改。
- 粘贴的楼栋可整体移动并调整宽高，楼内标注会随楼栋同步移动、缩放。
- 编辑视图可每次顺时针旋转 90°，不改变原始坐标和导出方向。
- “查看原图”是纯预览模式，会暂时隐藏全部人工标注并阻止误编辑；缩放和平移仍可使用。
- 支持点击起点和终点进行像素级全局路线验证，默认使用 0 px 障碍安全边距。
- 支持选择、移动、撤销、重做、缩放、平移和裁剪保留框。
- 导出后网页会自动切换为裁剪结果预览并隐藏黄色裁剪框；可用“显示完整地图”返回完整编辑范围，或再次选择“裁剪保留框”重新绘制。
- 导出严格黑白二值 PNG 和可重新导入的标注 JSON。
- 点击导出时自动保存本地工程；下次用同一张原图启动时自动恢复。
- 全程在本机处理，不上传地图。

## 安装

macOS 终端进入本目录后执行：

```bash
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
```

## 使用

```bash
./.venv/bin/python map_converter.py --input "/path/to/小区高德地图.jpeg"
```

脚本会生成初始底图并自动打开本地编辑网页。关闭终端中的脚本即可停止网页服务。

常用参数：

```text

--output-dir outputs  初始底图输出目录
```

## 导出和继续编辑

网页中的“导出 PNG + JSON”会下载：

- `*_binary.png`：最终白底黑线地图；设置裁剪框后只导出框内区域。
- `*_annotations.json`：包含原图尺寸、裁剪框、可行区、矩形障碍区、封闭填充障碍区、障碍线、楼栋组合及裁剪后坐标。

点击导出时，程序还会在本机的 `outputs` 目录保存 `*_editor_project.json`。以后使用同一张原图、从同一项目目录启动脚本时，网页会自动恢复到上次导出的状态，不需要再次手工导入 JSON。只有点击导出才会更新该本地工程，尚未导出的临时操作不会覆盖上次状态。

“导入标注 JSON”仍可用于换电脑、接收别人提供的工程，或者恢复某个历史版本。JSON 中保留的是原图坐标，因此即使导出时使用了裁剪框，也能正确恢复编辑状态。

Chrome 可能会把一次导出的两个文件识别为“多个文件自动下载”。如果地址栏显示“下载已被阻止”，请允许当前 `127.0.0.1` 本地网页下载多个文件，再重新点击导出。请确认 PNG 和 JSON 都实际出现在下载目录后再关闭网页。

## 发给别人使用

只使用转换和编辑工具时，把本仓库地址发给对方。对方执行：

```bash
git clone <仓库地址>
cd gaode-binary-map-editor
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
./.venv/bin/python map_converter.py --input "/path/to/map.jpeg"
```

只需要查看或处理最终黑白地图时，发送导出的 `*_binary.png` 即可。

需要继续编辑已有地图时，必须同时提供：

1. 完全相同的原始地图截图。
2. 对应的 `*_annotations.json`。
3. 本工具的仓库地址。

对方用原始截图启动网页后，点击“导入标注 JSON”即可恢复可行区、障碍区、障碍线、复制区域和裁剪框。原图尺寸必须与 JSON 记录一致。

`*_annotations.json` 是本编辑器的工程文件，不是 ROS/Nav2 地图格式。当前导出的 PNG 没有 `resolution`、`origin` 等实际尺度信息，因此不能单独作为完整的 Nav2 地图直接部署。

## 障碍区

- “矩形障碍区”用于楼栋、围墙等规则范围，直接拖出黑色矩形。
- “点击填充障碍区”用于已经被黑线完全封闭的不规则白色区域。第一次点击显示红色预览，再次点击红色区域才会确认填黑；按 `Esc` 可取消预览。
- 填充前会自动检查 1–8 px 的小缺口。若发现填充会从小缺口泄漏，地图会用橙色圆圈、十字和编号标出疑似位置，左侧同时显示像素坐标。切换“画障碍线”在标记处补线后，再重新点击填充；橙色标记在切换工具后会保留，按 `Esc` 可清除。
- 橙色标记是根据像素连通关系得到的疑似位置。缺口过宽、多个开口连在一起或边界结构过于复杂时，程序可能无法可靠定位；此时会明确提示放大后人工检查，不会直接误填大范围区域。
- 如果填充范围连接地图边缘，或超过整张地图的 35%，程序仍会拒绝填充，避免把道路和地图背景整体填黑。
- 封闭填充会作为 `obstacleFills` 保存到 JSON，可撤销、删除、导入和再次导出；为保证边界准确，填充区不能直接移动，需要调整时删除后重新填充。

## 复制缺失楼栋

1. 点击“框选复制楼栋”。
2. 先完成该楼栋内部的可行区、障碍区和障碍线修改。
3. 直接拖出复制框；框多大就复制多大，框内所有黑白像素都会保留。
4. 程序不会再替你判断楼栋轮廓，也不会把范围缩小为某个自动识别结果。
5. 提取成功后会自动进入“粘贴楼栋”，移动鼠标预览并单击放置，可连续放置。
6. 切换到“选择编辑”，可移动复制区域，并在左侧调整宽、高；框内内容会整体同步变化。
7. 选中已粘贴楼栋后，也可以使用 `Command+C`、`Command+V` 连同内部布局再次复制粘贴。

复制楼栋采用所见即所得的矩形图块：道路、楼栋和人工标注只要落在框内都会被复制。因此框选范围完全由你决定，程序不会自动排除道路。图块会一并保存到标注 JSON 中，以便下次继续编辑。

“顺时针旋转 90°”只旋转网页中的编辑视图，便于从不同方向操作地图；标注坐标、裁剪坐标和最终导出的 PNG 方向保持不变。

障碍线默认启用“水平/垂直吸附”：第二个点会自动落到更接近的水平或垂直方向。取消勾选即可画斜线；已有斜线不会被自动修改。若只想校正某一条线，先选中它，再点击“将选中线调整为水平/垂直”。

## 全局路线验证

1. 点击“验证全局路线”。
2. 在当前地图上点击起点，再点击终点。
3. 规划器实时合成尚未导出的编辑结果，以白色为可行区域、黑色为障碍，通过 A* 计算路线。
4. 起点或终点误点到黑色障碍时，会在 40 px 范围内吸附到最近白色区域；画面用“起”“终”和箭头显示实际路线方向。
5. 默认障碍安全边距为 0 px，直接验证原始像素连通性；需要主动封住细小断口时可调大该数值。
6. 规划成功后会在不穿越黑色障碍、不斜穿障碍角的前提下合并冗余折线节点，使斜向和弯道路段更平顺。

显示“规划成功：本次路线连通，编辑验证 OK”只证明本次所选起点到终点连通，不代表整张地图所有区域都已验证。路线、起点和终点仅为临时验图覆盖层，不写入标注 JSON，也不会出现在导出的二值 PNG 中。地图一旦被修改，旧路线会自动失效。

## 适用范围

第一版针对示例中的浅绿色背景、浅灰色道路和楼栋的高德小区地图截图。自动结果是人工编辑的起点，不应直接当作机器人可部署地图；请在导出前检查道路边界、楼栋轮廓和被文字遮挡的位置。
